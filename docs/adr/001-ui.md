# ADR 001: Native Rust UI

Accepted for the development build after the owner delegated the stack choice. Use Rust and windows-rs with native Win32 controls and Direct2D content. The available MSVC/Rust toolchain compiled and ran the application. Keep rendering off the UI thread.

C#/WinUI NativeAOT remains a credible alternative with stronger ready-made modern controls. No comparable benchmark proved it slower. A browser shell conflicts with the no-web-view requirement. Raw native controls reduce framework setup but leave more accessibility and modern styling work. That cost remains visible in the acceptance checklist.

Evidence: [Windows Rust bindings](https://github.com/microsoft/windows-rs), [WinUI NativeAOT](https://learn.microsoft.com/windows/apps/windows-app-sdk/release-notes-archive/stable-channel-1.6), `../verification.md`.
