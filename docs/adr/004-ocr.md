# ADR 004: Windows OCR

Use Windows.Media.Ocr lazily on the worker. A real local Windows 10 test recognized the expected phrase and digits. Composite transparency onto white before recognition and report missing OCR languages explicitly.

Copilot+-only recognition cannot serve this host or the full target audience. A bundled OCR model adds setup and size before a demonstrated need. Text extraction is available now; hover word selection and multilingual accuracy are not yet accepted.

Evidence: [OcrEngine API](https://learn.microsoft.com/uwp/api/windows.media.ocr.ocrengine), `../ocr-verification.md`.
