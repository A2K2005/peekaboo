# ADR 002: PDFium

Use the pinned non-V8 x64 PDFium DLL and direct native bindings on one worker. Real round-trip tests demonstrate the implemented operations. MuPDF is excluded by the user's license constraint. No GPL/AGPL code is copied from reference apps. qpdf is not needed for the current unencrypted Save Copy path and is not bundled.

Do not infer complete PDF support: XFA/JavaScript forms, encrypted exports, digital-signature preservation, reading-order guarantees, and cross-reader annotation appearance need further work. Saves produce new files; incremental autosave is not implemented.

Evidence: [PDFium public headers](https://pdfium.googlesource.com/pdfium/+/refs/heads/main/public/), [binary distributor](https://github.com/bblanchon/pdfium-binaries), [MuPDF licensing](https://mupdf.com/licensing/).
